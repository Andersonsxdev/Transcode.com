¿Qué es el sistema binario?

El sistema binario es un sistema de numeración que utiliza base 2. Esto significa que solamente utiliza dos símbolos diferentes para representar todos los números y datos. Estos símbolos son: 0 y 1.

Cada posición dentro de un número binario representa una potencia de 2. Este sistema es el lenguaje fundamental de la informática y la electrónica digital, ya que los circuitos electrónicos operan internamente con dos estados de voltaje: encendido (1) y apagado (0).

Uso del sistema binario en informática

En programación y arquitectura de computadoras el sistema binario se utiliza para representar absolutamente toda la información procesada por un sistema: instrucciones de CPU, imágenes, texto y archivos.

Cada dígito binario se denomina bit (Binary Digit), y al agrupar ocho bits se forma un byte, la unidad básica de almacenamiento en la mayoría de los sistemas computacionales actuales.

Conversión Manual

Para convertir un número decimal a binario se utiliza el método de divisiones sucesivas entre 2. Se divide el número entre 2 y se guarda el residuo. Luego el resultado se vuelve a dividir entre 2 hasta que el cociente sea 0. Finalmente los residuos se leen desde el último hasta el primero.

Ejemplo

13 ÷ 2 = 6 residuo 1
6 ÷ 2 = 3 residuo 0
3 ÷ 2 = 1 residuo 1
1 ÷ 2 = 0 residuo 1

Leyendo los residuos desde abajo hacia arriba obtenemos:

13 en decimal = 1101 en binario

        cout <<" CONVERSION DE BINARIO A DECIMAL " << endl;

    }

        if (vbinario == "0") {

            cout << "Decimal: 0" << endl;
            return;	
        }

        int d = stoi(vbinario);
        int exponente = 1;

        while (d > 0) {

            int valord = d % 10;
            valordecimal = valordecimal + valord * exponente;
            exponente = exponente * 2;
            d = d / 10;
        }

        cout << "El valor decimal es :" << valordecimal << endl;
    }
};

	binade bad;
	bad.pedirvbin();
	bad.cambio();
	return 0;
