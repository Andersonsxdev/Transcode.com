¿Qué es el sistema octal?

El sistema octal es un sistema de numeración que utiliza base 8. Esto significa que solamente utiliza ocho símbolos diferentes para representar todos los números. Estos símbolos son: 0, 1, 2, 3, 4, 5, 6 y 7.

Cada posición dentro de un número octal representa una potencia de 8. Este sistema fue muy utilizado en informática en los primeros años de las computadoras porque permitía representar números binarios de una forma más compacta y fácil de leer.

Uso del sistema octal en informática

En programación y arquitectura de computadoras el sistema octal se utilizaba para simplificar la representación de números binarios. Cada dígito octal representa exactamente tres bits en binario.

Por esta razón muchos sistemas antiguos utilizaban números octales para representar direcciones de memoria, permisos de archivos y configuraciones internas del sistema.

Conversión Manual

Para convertir un número decimal a octal se utiliza el método de divisiones sucesivas entre 8. Se divide el número entre 8 y se guarda el residuo. Luego el resultado se vuelve a dividir entre 8 hasta que el cociente sea 0. Finalmente los residuos se leen desde el último hasta el primero.

Ejemplo

125 ÷ 8 = 15 residuo 5
15 ÷ 8 = 1 residuo 7
1 ÷ 8 = 0 residuo 1
